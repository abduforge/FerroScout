# Security policy

FerroScout is a local static-analysis tool. It does not execute scanned files or contact remote systems.

Please do not submit real credentials, private keys, or confidential source code in public issues. For a suspected security issue in FerroScout itself, contact the repository maintainer privately through GitHub's supported security reporting mechanism when available.

Findings produced by FerroScout are heuristic review leads. They are not proof of exploitability and do not guarantee complete coverage.
