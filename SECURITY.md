# Security policy

FerroScout is a local static-analysis tool. It does not execute scanned files or contact remote systems. Findings are heuristic review leads, not proof of exploitability, and the tool does not guarantee complete coverage.

## Reporting a vulnerability in FerroScout

Please do not open a public issue containing an exploitable vulnerability, real credentials, private keys, confidential source code, or personal data.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository:

https://github.com/abduforge/FerroScout/security/advisories/new

If private reporting is unavailable, contact the maintainer through a private GitHub channel and share only the minimum information needed to reproduce the issue. Do not include live secrets; use synthetic replacements.

## Scope

This policy covers the FerroScout application and its repository workflows. A finding produced by FerroScout in another project is not automatically a vulnerability in FerroScout itself.
