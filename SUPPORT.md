# Support

For help using FerroScout:

- Read the command reference: `ferroscout --help`.
- Check [README.md](README.md) or [README_RU.md](README_RU.md).
- Search existing [Discussions](https://github.com/abduforge/FerroScout/discussions) or open a Q&A discussion.
- Report reproducible bugs through [Issues](https://github.com/abduforge/FerroScout/issues/new/choose).

Please use synthetic examples. Do not post real passwords, tokens, private keys, private source code, or personal data.

For security issues in FerroScout itself, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
